# VideoCourts — Virtual Court System

Sovereign virtual court platform with biometric authentication, AI agents, and decentralized case management.

## Architecture
- **Frontend:** React components (`frontend/src/components/VideoCourt.js`)
- **Backend:** Node.js server (`frontend/backend/server.js`)
- **API Layer:** Python API gateway (`api.py`)
- **Agents:** Autonomous court agents (`agents/`)
- **Biometric:** Authentication subsystem (`biometric/`)

## Deployment
Deployed via Vercel. Configuration in `vercel.json`.
