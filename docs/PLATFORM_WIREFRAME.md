# VideoCourts™ Wireframe & User Flow
## Core Journeys
1. Citizen: Bio-Auth -> Case Search -> Request ($1.99) -> Court Review -> Pay ($19.99) -> Enter Courtroom
2. Attorney: Login -> Dashboard -> E-File -> Schedule -> Join Virtual Court -> Evidence Vault
3. Judge: Console -> Review Requests -> Approve -> Conduct Hearing -> Sign Orders -> Archive
